# 📋 Финальное ТЗ: «Оживить option-exchange (YZoZ)»

**Контекст.** Проект — заброшенный прототип крипто-биржи опционов (2018). Запуск уже подтверждён сквозным сценарием (signup → orders → matching → river). Цель ТЗ — превратить прототип в воспроизводимо запускаемое и расширяемое приложение. **Лицензия меняется на MIT, лицензионных шапок в код не добавляем.**

Маркировка: 🔴 P0 / 🟠 P1 / 🟡 P2. Формат asset-строки — `TICKER_EXP_STRIKE_C|P` (напр. `ETH_BTC_1519862400_100000_C`).
