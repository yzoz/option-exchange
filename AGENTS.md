# Карта проекта

Этот файл — только карта. Детали лежат в отдельных документах. Читай их только
тогда, когда задача действительно этого требует.

## Когда что читать

- **Как поднять проект с нуля / запуск, порты, типовые ошибки** →
  `docs/RUNBOOK.md`. Читай, если запускаешь стек, правишь `Makefile`/compose или
  что-то не стартует.
- **Архитектура, доменная модель, HTTP-интерфейсы, правила кода** →
  `docs/DEVELOPER_GUIDE.md`. Читай перед крупной фичей или если непонятно, как
  связаны модули и как устроен `asset`-формат.
- **План работ, приоритеты, статус задач** → `docs/SPEC.md`. Читай, чтобы понять,
  что уже сделано и что ещё входит в текущий этап.
- **Журнал выполненных блоков** → `docs/DONE.md`. Читай перед началом работы над
  новым блоком, чтобы не наступить на уже пройденное.
- **Общее описание проекта и компонентная схема** → `README.md`. Читай первым,
  если нужно быстро понять, что это вообще за проект.

## Чего не делать

- Не читай файлы из `docs/` «на всякий случай» — только по условию выше.
- Не загружай весь `docs/` целиком: `DONE.md` и `DEVELOPER_GUIDE.md` большие.
- Если информации в `AGENTS.md` достаточно для задачи — не открывай остальные
  файлы.
